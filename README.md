# rubik-solver

A cross-platform mobile app (Android & iOS) that helps anyone — from 6-year-olds to adults — solve a Rubik's cube
(2x2 and 3x3): scan or enter the cube, follow an animated 3D step-by-step guide, and learn the techniques in tutor
mode until the app is no longer needed.

## Status

**Phase 7 & 8 — Complete v1 (Camera Scan, 3D Guide, Strategy Solvers, Tutor & Profiles).**
